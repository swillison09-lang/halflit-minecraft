# Minecraft Chromebook Edition (HALFLIT)

The built game, published with GitHub Pages and embedded on the HALFLIT games site
(https://sites.google.com/view/halflit/minecraft-chromebook-edition).

This repository only holds the build output (`index.html`). The source lives in the
`mc-chromebook` project; `node deploy-web.mjs` there builds the game and pushes it here.

Not an official Minecraft product. Not approved by or associated with Mojang or Microsoft.
